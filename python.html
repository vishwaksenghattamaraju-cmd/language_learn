How Python Compilation Works

While Python is often called an interpreted language, it automatically compiles source code to bytecode before execution.

Phase 1
📄

Source Code

You write readable human code in .py files using indentation, functions, and standard libraries.

script.py
Phase 2
⚡

Bytecode Compiler

The parser builds an AST, which the internal compiler translates into platform-neutral bytecode instructions.

__pycache__/*.pyc
Phase 3
🔄

CPython PVM

The Python Virtual Machine (PVM) iterates through bytecode instructions and executes them on your machine's CPU.

CPython Evaluation Loop

Step-by-Step Installation by Operating System

Select your operating system below for tailored instructions to install Python and configure environment variables.

1

Download the Official 64-bit Installer

Grab the latest Windows installer (e.g., python-3.x.x-amd64.exe) from the official download link at the bottom of this page.

2

Enable 'Add python.exe to PATH' (Critical)

When launching the installer, look at the very bottom of the first setup window. You MUST check the box:

⚠️

Crucial Setup Step

Ensure [✔] Add python.exe to PATH is checked before clicking "Install Now". This registers Python in your terminal so commands like python and pip work globally.

3

Complete Installation & Disable Path Length Limit

Click "Install Now". On the successful completion screen, click "Disable path length limit" if prompted. This prevents file path length errors when dealing with complex node/python libraries.

4

Alternative: Windows Package Manager (Winget)

If you prefer installing via PowerShell or Command Prompt, run:

PowerShell / Command Prompt 
winget install -e --id Python.Python.3.13
1

Method 1: Install via Homebrew (Recommended)

Homebrew is the cleanest way to manage developer packages on macOS without altering system-level libraries:

macOS Terminal (zsh) 
brew update && brew install python
2

Method 2: Official macOS Universal Installer (.pkg)

Download the .pkg file from the bottom of this page. Double-click the downloaded package and follow the standard macOS installation wizard. It installs Python and updates your shell profile automatically.

3

Verify Default Alias in zsh

On modern macOS versions, the default shell is zsh. You can alias python to python3 in your ~/.zshrc file:

macOS Terminal (zsh) 
echo 'alias python="python3"' >> ~/.zshrc && source ~/.zshrc
1

Update System Repositories

Update your package index to ensure you download the latest security patches and runtime versions:

Bash (Ubuntu / Debian) 
sudo apt update && sudo apt upgrade -y
2

Install Python 3, Pip & Virtual Environments

Install the core Python interpreter along with the standard package manager and venv package:

Bash (Ubuntu / Debian) 
sudo apt install -y python3 python3-pip python3-venv build-essential

Verifying Your Python Setup

Open a new terminal window (restart terminal if it was already open) and test that Python and Pip respond correctly.

Check Compiler & Package Manager Versions 
python --version
pip --version

Run a quick interactive one-liner to verify runtime execution:

One-Liner Verification Test 
python -c "print('Python compiler and environment operational!')"
🔧

Troubleshooting: 'python' is not recognized

If your terminal reports that 'python' is not recognized as an internal or external command on Windows, you likely forgot to check "Add Python to PATH" during installation. To fix this without reinstalling:

1. Press Win + S and search for "Environment Variables".
2. Click "Edit the system environment variables" → "Environment Variables".
3. Under User variables, select Path and click Edit.
4. Add: %LOCALAPPDATA%\Programs\Python\Python3xx\ and %LOCALAPPDATA%\Programs\Python\Python3xx\Scripts\.
5. Restart your terminal window.
